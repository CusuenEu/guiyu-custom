# 归屿 20261102(07) Windows

- 点击“更新并重启”后，程序内部下载匹配位数的官方安装包，显示下载进度，校验 SHA256 后退出，自动安装到原位置并重新打开。
- 更新助手通过独立 Windows 进程启动，修复旧程序退出后安装交接中断的问题；下载或校验失败时保持原程序运行。
- 保留 06 的目录及分组拖动排序、插入线、磁盘根关联、左栏文件和文件夹展示、无可靠推荐时独立手动搜索，以及右键命名参数修复。
- 提供 ia32／x64 的 EXE、ZIP 和 SHA256SUMS.txt。

04 及更早版本只会打开下载链接，需要先手动安装一次 07，之后的新版才能使用程序内自动下载、安装和重启。06 已带有程序内下载入口，但旧版本的退出交接仍可能失败。配置与原文件保留，Mac 版本不变。

此发行必须在同一提交的 Windows 双架构测试、实际安装卸载、打包界面回归，以及实际自动下载／安装／重启回归全部通过后正式发布。
