# 归屿 20261103(01) Windows

- 新增文件／文件夹右键复制、粘贴和 Ctrl+C／Ctrl+V，多选支持与 Windows 资源管理器互通。
- 按操作栏位判断粘贴位置：左栏目录、中栏所选文件夹、右栏当前子文件夹；空目录和列表空白处也可粘贴。输入框和弹框继续编辑文字。
- 完整复制文件夹，保留原件，同名自动编号；复制结果置顶选中，刷新保留本次运行的优先顺序。禁止复制文件夹到自身或内部，父子项去重；异步执行并阻止重复提交，部分失败报告结果并清理未完成副本。
- 新增、修改、导入分类规则后，当前右栏立即切换按类别；切换项目或进入其他目录恢复默认分类。支持手动切换按时间／源文档。
- 手动分类优先，未匹配或冲突归入“其他”；没有创建该分类时仅展示兜底组，不写入设置。UUID 标识的用户“其他”分类同样识别。
- 重新分类时清除“刚复制”临时分组，文件按实际规则归组。仅显示当前目录直接内容，不移动源文件，不新增正文扫描、OCR 或云端请求。
- 保留 45 类文件图标、拖动排序、盘符关联、归档搜索及自动下载安装重启。

提供 ia32／x64 的 EXE、ZIP 和 SHA256SUMS.txt。07／08 可通过“更新并重启”自动升级；04 及更早版本需手动运行一次新版安装包。Mac 版本独立发布。
