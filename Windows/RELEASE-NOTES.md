# 归屿 20261102(02) Windows

智能命名新增“确认并归档”：

- 按钮位于“取消”和“确认重命名”之间，支持单个及批量智能命名。
- 先按编辑后的名称执行重命名，全部成功后，用新路径及新文件信息打开智能归档弹框。
- 归档仍需选择目标项目并最终确认；取消归档保留新名称，不移动文件。
- 重名、文件变化或批量部分失败时停止，不进入归档；操作中防止重复提交。
- 保留资源管理器右键菜单、桌面图标、下载／桌面来源、文件复制和正式版本更新检测。

提供 Windows 10 ia32 与 Windows 10/11 x64 安装包及完整 ZIP 解压包。Mac 版本保持 20261101(01)，自动更新通道不变。
