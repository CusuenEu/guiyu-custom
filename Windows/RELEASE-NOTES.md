# 归屿 20261102(04) Windows

- 修复资源管理器右键“智能命名／智能归档”报“无法打开所选文件”、ENOENT 的问题：不再把 `--allow-file-access-from-files` 等启动参数当作文件路径。
- 应用已运行时通过原始参数交接所选文件；兼容 Electron 插入或重排参数，并等待应用初始化完成后再处理右键请求。
- 支持中文、空格及特殊字符的文件／文件夹路径，保留原有右键入口，无须手动重新注册。
- 保留 03 版的目录浏览、多选复制、桌面来源和“确认并归档”等功能。

提供 Windows 10 32 位（ia32）及 Windows 10／11 64 位（x64）的 EXE 安装包、ZIP 解压包及 SHA256 校验清单。已有用户请关闭归屿后安装新版本，或解压后运行新版；用户配置保留。

发布前执行双架构逻辑测试、安装／卸载集成检查，以及真实打包程序的第二实例智能命名和智能归档回归。Mac 版本和自动更新通道不受影响。
