# 归屿 20261102(05) Windows

- 关联的项目总目录分组可拖动排序；组内文件和文件夹也可排序。拖到可放置位置会显示横向插入线，松开后保存；支持插入到前后及最后，刷新／重启保留顺序。
- 允许关联整个盘符（如 D:\、E:\），修复根路径范围判断。关联磁盘或文件夹后，最左侧直接显示其内部的文件和文件夹；整盘关联只读取直接内容，进入目录时再读取，避免全盘深层扫描。
- 智能归档不再因“贵州、服务、项目”等泛词推荐无关项目；没有明确匹配时显示“暂无可靠推荐”，用户可自行输入项目名搜索。
- 新增“更新并重启”：自动下载官方安装包、核对 SHA256、退出旧程序、安装到原位置并重新打开。下载／校验失败保持旧程序运行，用户配置保留。
- 保留 04 版右键智能命名／智能归档的启动参数修复。

04 及更早版本需先手动安装一次此版本，之后才具有新的自动安装能力。历史缺少校验信息或仅有 ZIP 的更新包保留手动下载。提供 ia32／x64 的 EXE、ZIP 和 SHA256SUMS.txt。Mac 版本及更新通道不变。
