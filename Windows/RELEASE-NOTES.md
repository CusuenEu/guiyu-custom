# 归屿 20261102(01) Windows

- 安装时自动加入文件、文件夹右键菜单：归屿-智能命名、归屿-智能归档。
- 安装时在当前用户桌面创建“归屿”启动图标，卸载时清理对应菜单和图标。
- 取消界面及新包文件名中的测试版标记，提供 32 位和 64 位安装包、ZIP 解压包。
- 可归档目录以“桌面”替换“最近使用”，保留下载和自定义关联；已有配置升级时自动迁移。
- 选中文档或文件夹按 Ctrl+C，可在资源管理器 Ctrl+V 粘贴，支持多选；输入框仍保留文字复制。
- 修复更新检查：按 Windows 独立版本和程序位数匹配，正式发布优先，下载指向相应安装包。

Windows 10 32 位选择 ia32；Windows 10 / Windows 11 64 位选择 x64。安装包运行 setup.exe；ZIP 需要解压整个文件夹后运行 Guiyu.exe，右键入口可在设置中安装。

取消测试版标记不改变已记录的系统适配范围：尚无 Windows 代码签名和签名自动安装更新，真实 Explorer 粘贴及各 Windows 10/11 设备交互仍需验收。使用说明见 Windows/README.md。
