# 归屿 20261031(02)

本版更新项目浏览、文件分类与智能命名工作流。

- 设置新增“命名规则”：文件夹和文档分别选择“月份＋识别名称”“月日（如1001）＋识别名称”或“分类＋识别名称”；单项、批量智能命名共用规则，保留扩展名，确认后才改名。
- 智能命名、智能归档采用统一的森林绿原生弹框；归档搜索切换时清除旧选择，避免误归档。
- 文件分类采用清晰的三步豆包操作流程：直接复制提示词、发送并复制回复、直接读取剪贴板录入规则；提供三张离线图解。
- 新用户首次安装默认无分类；右侧“请设置文件分类”入口直接打开对应设置，已有用户的分类与规则保留。
- 完善多项目总目录、目录拖动、三级文件名搜索及分类规则管理。
- 设置提供“检查更新／立即更新”，下载和安装由用户明确发起。

验证：Apple Silicon 本地构建、隔离自测、原生界面渲染、代码签名与 Sparkle 更新签名校验。首次安装需 macOS 13+ 与 Apple Silicon。当前未采用 Apple Developer ID 签名／公证。
