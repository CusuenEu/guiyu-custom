# 归屿 20261101(01) · macOS

智能命名新增双栏预览与本机框选识别：

- PDF 预览前两页，图片预览单页；支持缩放、滚动和旋转。
- 拖出矩形即可识别选中区域，使用 macOS 自带 Vision，无需安装额外 OCR，也不上传文档。
- 识别结果可编辑，支持选用部分文字；自动推荐和手动命名继续可用。
- 保留原扩展名，确认后才改名；切页、编辑或关闭时取消过期识别。

适用于 Apple Silicon Mac，macOS 13 或更新版本。下载 ZIP 后解压，将归屿.app 放入“应用程序”。本次仅发布 Mac 安装包。
