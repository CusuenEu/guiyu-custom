# 归屿 20261102(01) · Mac 更新

- 智能命名新增“确认并归档”，位于取消和确认重命名之间；改名成功后打开归档弹框，确认归档后才移动文件。取消归档会保留已完成的命名。
- 文件、文件夹和侧栏目录支持 ⌘C 复制，可在 Finder 粘贴；输入框仍复制文字。
- 修复数字、月份、日期文件夹因内部文件名产生无关归档推荐的问题，提高自动推荐的匹配要求，保留手动搜索选择。
- 修复设置窗口阻止更新安装退出，以及更新中断后按钮状态不恢复的问题。
- 新增标准 DMG 安装包：打开后将归屿拖入“应用程序”。自动更新继续使用签名 ZIP。
- 开发自测与安装测试隔离 Finder 服务，提供重复测试服务的定向清理工具。

适用于 macOS 13+、Apple Silicon。仅发布 Mac；Windows 保持其独立版本与下载。完整构建、自测、隔离安装验证和签名检查通过。首次安装仍采用本地签名，尚未 Apple Developer ID 公证。
