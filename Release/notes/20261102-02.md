# 归屿 20261102(02) · Mac 更新

- 接入 45 类彩色文件格式图标、334 个扩展名映射，覆盖办公文档、PDF、图片、思维导图、CAD／BIM、Project、专业绘图、网页代码、媒体和系统文件。
- 文件列表、项目内文件、搜索结果、下载／最近使用列表和归档摘要共用同一套图标。
- 按实际扩展名识别，不按文件用途猜测；普通目录保留原文件夹图标，未知格式使用通用图标，Finder 替身显示快捷方式图标。
- 复用图标包的 Swift 映射和 Asset Catalog，保留多倍率图片和来源许可；图标显示不读取文档正文。

适用于 macOS 13+、Apple Silicon。提供 DMG、自动更新 ZIP、签名更新清单和 SHA256 校验文件。Windows 版本及安装包不变。
