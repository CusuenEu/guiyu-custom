# 归屿 0.5.0

首个 GitHub 公开发行版，MIT 开源。

- 原生 macOS 三栏项目文件管理与本地 GRDB 文件名索引。
- 支持按类别、时间和源文档浏览、推荐命名与确认归档。
- 内置 Sparkle 2：自动检查、下载并安装后续更新，可在菜单中关闭。
- HTTPS 更新清单及安装包均进行 Ed25519 验签，无需自建服务器。

## 安装

macOS 13+，当前官方包仅适用于 Apple Silicon（arm64）。下载 ZIP 解压，将归屿.app 拖到“应用程序”。首次免费签名版本未经过 Apple Developer ID 签名/公证，系统可能拦截；确认官方来源后，在系统设置“隐私与安全性”查看“仍要打开”。

0.4.x 用户需先手动安装本版一次。应用与索引数据保存在本机，更新不会打包或上传你的项目文件。自动更新依赖 GitHub 网络可达。
