# 归屿 20261103(01) · Mac 更新

- 支持应用内右键复制／粘贴和 ⌘C／⌘V，可与 Finder 互相复制文件，支持多项和完整文件夹。
- 左侧选 A、中间未选文件夹时粘贴到 A；中间选 B 时粘贴到 B；点击右侧空白处时粘贴到右侧当前目录。新副本置顶并自动选中，同名编号不覆盖。
- 新增或修改分类后，当前目录立即按规则分组；选择其他项目或进入子文件夹时默认按类别，仍可手动切换其他视图。
- 修复未匹配文件误归到第一个分类的问题；没有设置“其他”时使用展示兜底，手动指定分类优先保留。
- 新增 Windows 开发需求说明，列明对应交互和验收场景。

适用于 macOS 13+、Apple Silicon。提供 DMG、自动更新 ZIP、签名更新清单及 SHA256 校验文件。Windows 版本和安装包保持不变。
