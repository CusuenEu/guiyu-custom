# 归屿使用与构建说明

[返回首页](../README.md) · [更新日志](../CHANGELOG.md) · [下载与发行记录](https://github.com/tiduse1988/guiyu/releases)

## 安装

### macOS

要求 macOS 13 或更高版本，官方安装包适用于 Apple Silicon（M 系列）。

1. 下载 DMG，打开后将“归屿.app”拖入“应用程序”。
2. 复制完成后推出安装磁盘，从“应用程序”打开归屿。
3. 若下载 ZIP，先完整解压，再将应用拖入“应用程序”。

当前版本尚未使用 Apple Developer ID 签名及公证。首次打开若被系统拦截，确认从官方仓库下载后，在“系统设置 → 隐私与安全性”查看“仍要打开”。组织管理的设备可能需要管理员协助。

设置左下角可检查更新，发现新版后点击“立即更新”，按提示完成。更新需要联网，本地文件管理可离线使用。

### Windows

Windows 10 / 11 的 64 位系统选择 x64，Windows 10 的 32 位系统选择 ia32。

双击 EXE 安装包并按向导安装，无需另装 Node.js。ZIP 版需完整解压后运行 `Guiyu.exe`，不要只复制 EXE 文件。安装包提供桌面图标及文件、文件夹的右键入口；Windows 11 中可能位于“显示更多选项”。

Windows 更新方式以对应版本的发行说明为准。平台差异、OCR 与 Office 支持范围见 [Windows 详细说明](../Windows/README.md)。

## 开始使用

1. 在“文件位置”或左栏“＋”关联已有的项目总目录。
2. 选择目录和项目，浏览文件；在“文件分类”中设置自己的分类。
3. 右键文件或文件夹，选择“智能命名”或“智能归档”。

关联目录只添加入口，不移动原文件。普通浏览和名称搜索不读取文档正文；识别在用户发起命名或归档时按需进行。

## 智能命名

读取文件自身的标题，展示推荐名称；没有明确标题时保留原名。可修改名称，确认后才真正改名，原扩展名保留。

Mac 单文件命名支持 PDF 前两页及单页图片预览、缩放、旋转和框选文字识别。识别文字可以纠错，也可只选用其中一部分。Word、Excel 等格式保留标题推荐和手动命名。

支持文件夹及批量命名。设置中的“命名规则”可分别为文件夹、文档选择仅名称、月份、月日或分类前缀；默认仅名称。

点击“确认并归档”会先完成命名，再打开归档窗口。取消后续归档会保留已经确认的新名称。

## 智能归档

从下载、关联来源或项目目录选中文件，查看推荐项目，或输入名称搜索目标。

选定目标并确认后才移动，同名自动编号且不覆盖，文件夹内部层级保留。没有可靠推荐时可手动选择。归档记录在原位置未被占用、文件身份未变化等条件下支持撤销。

## 浏览、分类与搜索

按类别、时间或原始层级浏览当前目录；名称搜索支持空格分隔的多个关键词，不搜索正文。分类只影响展示分组，不移动文件。

Mac 支持空格预览、Return 更名、⌘C 复制、⌘O 打开及 ⌘／Shift 多选；Windows 快捷键见其详细说明。

Finder 中可通过右键“服务”调用归屿命名和归档；未显示时，先将应用安装到“应用程序”，再按仓库中的 `install-finder-services.sh` 刷新注册。

## 复制与粘贴（Mac 本地开发版）

文件、文件夹支持右键“复制／粘贴”和 ⌘C／⌘V，也可粘贴从 Finder 复制的文件。

- 左侧选 A，中间未选文件夹：粘贴到 A 内。
- 中间选 B：粘贴到 B 内。
- 点击右侧空白处：粘贴到右侧当前打开的文件夹，包括子文件夹和空文件夹。

新副本置顶并自动选中；按类别、按时间视图在顶部显示“刚复制”，原始层级视图直接置顶。本次运行中刷新会保留复制项的优先顺序。原文件不移动，同名自动编号、不覆盖。输入框仍按正常文字编辑处理 ⌘C／⌘V。

此功能尚未发布到正式安装包。

## 从源码构建

macOS 安装支持 Swift 6 的 Xcode / Command Line Tools 后运行：

```sh
git clone https://github.com/tiduse1988/guiyu.git
cd guiyu
./build.sh
open dist/归屿.app
```

首次构建需联网获取锁定依赖。Windows 构建步骤见 [Windows 开发说明](../Windows/README.md#开发)。
