# 归屿 Windows 开发需求 · 2026-11-03

本次同步两项 Mac 已实现的功能：**复制粘贴**、**自动分类展示**。请在 Windows 版实现相同的使用逻辑，快捷键使用 Ctrl+C／Ctrl+V。

## 1. 复制与粘贴

### 粘贴位置

| 当前操作 | 粘贴到哪里 |
| --- | --- |
| 左侧选文件夹 A，中间未选文件夹 | A 内 |
| 左侧选 A，中间选文件夹 B | B 内 |
| 点击右侧空白处 | 右侧当前打开的文件夹内，包括子文件夹和空文件夹 |

根据当前选择和当前操作的栏位决定目标；右侧显示着旧项目时，不能误用旧项目作为左侧／中间操作的目标。点击左侧 A 后应清除中间旧选择。

### 操作入口

- 文件、文件夹支持右键“复制”和 Ctrl+C，支持多选。
- 右键“粘贴”和 Ctrl+V 共用一套目标判断；列表空白处和空目录也可右键粘贴。
- 支持从 Windows 资源管理器复制文件后，在归屿粘贴；归屿复制的文件也可在资源管理器粘贴。
- 输入框取得焦点时，Ctrl+C／Ctrl+V 继续复制粘贴文字；不能操作背后的文件。
- 剪贴板没有文件，或没有有效目标目录时，文件粘贴不可用；弹框中的文字编辑不触发背景文件操作。

### 复制结果

- 复制文件夹时包含内部全部内容，原文件保留。
- 新副本显示在最上方并自动选中，多项复制保持顺序。
- 按类别／按时间视图可在顶部显示“刚复制”组，源文档视图直接置顶。本次运行中，普通刷新保留复制项优先顺序。
- 同名自动编号，例如“合同 (2).pdf”，保留扩展名，不覆盖已有文件。
- 不允许把文件夹复制到自身或内部，也不同时复制父文件夹及其内部条目。
- 大文件复制在后台进行，执行中避免重复提交。若部分失败，报告已完成数量和错误，原文件保留，未完成副本不能当作成功结果展示。

## 2. 自动分类展示

### 自动触发

- 新增分类后，当前打开文件夹的右侧立即切换到“按类别”，按最新规则重新分组，不用刷新或重新进入。
- 首次添加分类后，“请设置文件分类”直接变为当前文件夹的分类列表。
- 修改分类名称或规则后，当前列表立即更新。
- 在中间选择其他项目，或在右侧进入子文件夹时，右侧默认按类别展示。
- 用户仍可在当前文件夹手动切到“按时间／源文档”；进入另一个文件夹时恢复默认分类。

### 分类规则

- 复用已有的文件名／扩展名规则，使用用户最新保存的分类配置。
- 用户手动指定的分类优先保留。
- 未匹配或规则冲突的文件显示在“其他”，不能被塞进第一个分类，也不能从列表消失。
- 若用户没有创建“其他”，只增加一个展示用的“其他”分组，不额外写入分类设置。
- 用户自己创建的“其他”，即使内部 ID 是 UUID，也应作为真实兜底分类识别。
- 只分组当前目录的直接文件和文件夹，不展开其后代内容，不移动、重命名或修改源文件。
- 自动分组不新增正文扫描、OCR 或云端模型调用。

### 与复制置顶配合

刚粘贴完成时，副本先置顶选中。新增／修改分类、进入其他文件夹或主动选择“按类别”后，之前复制的文件按实际规则归组，不能一直留在“刚复制”而不分类。

## 3. 验收清单

| 场景 | 预期结果 |
| --- | --- |
| 复制项目，左侧选 A，中间未选文件夹，再粘贴 | 副本在 A 内，中间置顶选中 |
| 左侧选 A，中间选 B，再粘贴 | 副本在 B 内，右侧置顶选中 |
| 右侧进入 B 的子文件夹 C，点击空白处粘贴 | 副本在 C 内 |
| 空目录右键或 Ctrl+V | 能粘贴并立即看到副本 |
| 多选文件和文件夹，重复粘贴 | 完整复制、自动编号、原文件和已有副本保留 |
| 输入框 Ctrl+V | 只粘贴文字 |
| 从“源文档／按时间”新增“合同”分类 | 当前目录立即按类别分组 |
| 添加第一个分类 | 设置提示消失，当前目录内容按类别显示 |
| 修改规则，随后切换项目／进入子文件夹 | 当前及新目录均使用最新规则 |
| 只有“合同”分类，目录里还有普通说明文件 | 合同归合同，说明显示在“其他”，设置中仍只有一个分类 |
| 手动指定过分类的文件 | 自动分类后仍保留手动选择 |
| 之前复制的文件随后重新分类 | 归入实际分类，列表无重复、无遗漏 |

请在 Windows 实际安装包中验证菜单、快捷键、系统剪贴板和目录结果，并保留 x86／x64 的现有功能。
